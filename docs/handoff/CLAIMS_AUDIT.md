# 主张边界

对外描述必须区分开发集观察、算法效用、密码学机密性和解密后的表示隐私。
这一研究没有建立临床可用性或完整系统安全保证。

## 当前允许的表述

- 在开发分析集上，近满秩、零坐标噪声的 PCA 前缀通过预注册 PA-only 效用规则；
  已测试的非零坐标噪声未通过。
- 当前重建攻击能从秩 1024 和秩 1999 的零噪声释放中恢复可见胸片结构。
- 深度不超过 5 的像素学生未找到可行配置；当前锁定多项式塔在第 2 个 block
  发生数值非有限，因此没有计算有效 AUC。
- TenSEAL 只测量一个缩小的 CKKS block，不代表完整 InternViT 或端到端 VLM。

数字对应的协议规则见 `EVALUATION_PROTOCOL.md`，详细解释见
`docs/RESEARCH_NOTES.zh-CN.md`。病例级 JSON 和名单为本地证据，不应公开。

## 不支持的表述

- 加密后无损、保护了图像隐私或零信息泄漏；
- 已完成临床非劣效、临床验证或真实部署；
- 首创、首个 FHE Transformer、首个 HE ViT 或 SOTA；
- 将开发集上的零噪声效用结果写成确认集结论；
- 将 FHE、DP 记账、embedding cosine 或低重建误差中的任一单项当成完整隐私证明。

解密表示应单独评估重建、链接、属性推断和成员推断。任何新主张都应在评分与
攻击前锁定规则，并附带患者级划分、实现版本、结果字段和失败标志。
