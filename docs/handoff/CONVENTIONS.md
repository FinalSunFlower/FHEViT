# 研究与发布约定

## 判定

- 非劣效：同一批病人上 `AUC(release) - AUC(native)` 的单侧 95% 下界大于 −0.05。界本身等于 −0.05 不算通过。
- 高于机会：AUC 的单侧 95% 下界大于 0.5。0.500 不算通过。
- 胜过均值：改进量的双侧 95% 区间整个在 0 上方。
- 病人 bootstrap：2000 次，种子 42。单类抽样丢弃。有效抽样少于 100 则中止。
- 分位使用 `np.quantile`：单侧 0.05，双侧 0.025 与 0.975。bootstrap 标准差的 `ddof` 为 1。
- 格通过：五次抽取里至少四次单侧下界大于 −0.05。主终点是 PA-only。
- 噪声尺度 0 仍消耗噪声流，但不加到坐标上。零噪声惩罚是未归一化 gram 上的 `+I`，不除以 n。

## 固定输入

- 提示：`Does this chest X-ray show pneumonia? Answer Yes or No.`
- 分数：`logit(Yes) - logit(No)`。Yes 与 No 的词表编号以评分脚本里的分词结果为准，本页不另抄一份。
- 种子：编解码与模型 812，DP 噪声与抽样 1941，bootstrap 42。前沿噪声与细网格噪声都是 NumPy PCG64、种子 812，细网格用独立流。重抽训练子集是 PCG64、种子 42。
- 图像规则：§2.22 选定的那张片子保持不变。只有它是 PA，病人才进入 PA-only。AP 不换成后来的 PA。
- 无标签选片只看 PA/AP 和年龄 18–90，不读 `finding_labels`。

- 证据冲突时：JSON，然后代码，然后协议，然后其他文档。对不上的数字标 `[UNVERIFIED]`。
- 不在确认集上拟合，不用确认集选秩、选格或选超参。不打开 NIH 保留 598，也不打开 COVID final holdout 来评分。
- Git 操作必须限制在项目仓库内；不要将兄弟目录、个人环境或数据目录加入提交。
