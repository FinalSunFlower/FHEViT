# Public Figures

This directory contains aggregate learning-curve figures generated by the
maintained experiment scripts. The PNG and PDF files contain no patient images,
patient identifiers, cohort manifests, model weights, or raw result records.

## Included figures

| Figure | Generator | Scope |
|---|---|---|
| `densenet_pca_learning_curve` | `experiments/validate_pretrained_anchor.py` | Development-only frozen DenseNet anchor curve |
| `nih_densenet_pca_learning_curve` | `experiments/validate_nih_predictor_capacity.py` | Development-only NIH predictor-capacity curve |
| `nih_internvl_pooled_pca_learning_curve` | `experiments/validate_nih_self_prediction.py` | Development-only pooled InternVL2 self-prediction curve |

Each figure is an aggregate diagnostic, not a clinical performance claim and not
an encrypted-inference result. The corresponding source JSON, local feature
caches, cohort manifests, and model/checkpoint files remain excluded from the
public repository. The experiment protocol and limitations are documented in
[`../EVALUATION_PROTOCOL.md`](../EVALUATION_PROTOCOL.md),
[`../docs/handoff/STATUS.md`](../docs/handoff/STATUS.md), and
[`../docs/handoff/CLAIMS_AUDIT.md`](../docs/handoff/CLAIMS_AUDIT.md).

The current architecture diagram is maintained as editable Mermaid in
[`../docs/handoff/ARCHITECTURE_CURRENT.md`](../docs/handoff/ARCHITECTURE_CURRENT.md).
