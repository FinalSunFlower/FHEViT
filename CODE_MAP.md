# Maintained Code Map

Generated by `python experiments/audit_workspace.py --write`; check with `--check`.
Every maintained Python module is listed below. Public symbols identify entry points,
not independent novelty claims. A module with no incoming static import may be an
executable command, test, registry entry or external API; that alone is not dead code.

The active evaluation is a plaintext InternVL2-2B prefix study; the CKKS code is a
separate reduced-block prototype. The legacy interactive pipeline is retained as a
research baseline and is not the current scientific result.
Read docs/RESEARCH_NOTES.zh-CN.md and docs/handoff/STATUS.md for scope and evidence.
A module with no incoming static import may be a command, test, public API, or
reproduction baseline; import absence alone is not a deletion criterion.
